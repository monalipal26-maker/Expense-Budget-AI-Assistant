Expense & Budget AI Assistant

About the Project:
Expense & Budget AI Assistant is an Android application designed to help users manage their daily expenses and budgets 
efficiently.

Features:
- Track daily expenses.
- Manage monthly budgets.
- View expense history.
- AI Assistant interface.
- Simple and user-friendly design.

Technologies Used:
- Java
- XML
- Android Studio
- SQLite Database

Project Type:
BCA Academic Project

Developer:
Student Project

Future Improvements:
- Expense analytics and charts.
- Improved AI-based financial suggestions.
- Monthly expense reports.
